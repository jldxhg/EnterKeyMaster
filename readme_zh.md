## 💡 解决的问题
不同的网页规则各异：有些是 `Shift + Enter` 换行，有些是 `Ctrl + Enter` 换行，而大多数 AI 聊天（ChatGPT, DeepSeek, Claude）默认按 `Enter` 就会直接发送。这种混乱的规则极易导致消息还没写完就错发出去。

**EnterKeyMaster** 让你摆脱这种混乱，重新掌控 `Enter` 键的行为逻辑。

## 🚀 核心功能
* **自定义回车逻辑：** 自由设定 `Enter` 为换行、`Ctrl+Enter` 为发送，完美匹配你的输入习惯。
* **统一操作体验：** 无需再记哪个网站用哪种快捷键。一套规则，纵横全网。
* **分域名独立配置：** 支持为不同网站定制不同策略。例如：在 A 网站禁用修改，在 B 网站完全自定义。
* **全自动识别：** 智能识别全网聊天输入框，无需针对特定 AI 平台手动开启。
* **隐私安全：** 你的输入内容属于你自己。所有逻辑本地处理。

## 🔒 隐私政策
**EnterKeyMaster 不会收集、存储或传输任何个人数据或输入内容。**
* 所有按键映射逻辑均在本地浏览器运行。
* 无第三方追踪，无数据上报。
* 代码开源，接受社区监督。
